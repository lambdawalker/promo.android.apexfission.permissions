## LinkedIn

Open source and free to use under Apache 2.0, Android ApexFission Permissions helps Android teams show why a feature needs access.

What if scanning needs camera but narration is optional? Set required = false for microphone; the content receives PermissionGrants. Gate on required access and choose narration behavior using grants.isGranted(RECORD_AUDIO). If required access was already granted, content appears immediately and optional access is not requested automatically.
